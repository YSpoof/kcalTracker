# Kcal Tracker

Um app simples e offline para acompanhamento diário de calorias e peso, focado em tornar o registro do dia a dia rápido e sem atrito.

O app permite:

- Acompanhar o consumo diário de calorias.
- Definir uma meta diária de calorias.
- Registrar refeições.
- Acompanhar o peso ao longo do tempo.
- Definir uma meta de peso.
- Gerenciar tudo através de uma interface simples e otimizada para dispositivos móveis.

## Funcionalidades

### 🏠 Início

A tela inicial apresenta um resumo do dia atual:

- Calorias consumidas.
- Meta diária de calorias.
- Calorias restantes.
- Progresso em relação à meta diária.
- Ação rápida para registrar uma refeição.
- Resumo do dia.
- Últimas refeições registradas.

O principal objetivo dessa tela é tornar o registro de algo que foi consumido o mais rápido possível.

### 🍽️ Refeições

Na tela de **Refeições** e possível cadastrar presets para serem utilizados no dia-a-dia.

Cada presset possui:

- Nome.
- Calorias.

Por exemplo:

| Refeição         | Calorias |
| ---------------- | -------: |
| Café da manhã    | 450 kcal |
| Pão com manteiga | 220 kcal |
| Arroz com feijão | 350 kcal |
| Frango grelhado  | 450 kcal |

### ⚖️ Peso

A tela **Peso** armazena os registros de peso ao longo do tempo.

Cada registro contém:

- Data.
- Peso.

Os registros são apresentados cronologicamente, permitindo acompanhar rapidamente a evolução do peso.

### ⚙️ Ajustes

A tela **Ajustes** contém as configurações do aplicativo.

Atualmente estão planejadas:

#### Metas

- Meta diária de calorias.
- Meta de peso.

#### Backup e restauração e limpeza

O usuário poderá:

- Exportar os dados do aplicativo.
- Importar um backup anterior.
- Redefinir seus dados.
